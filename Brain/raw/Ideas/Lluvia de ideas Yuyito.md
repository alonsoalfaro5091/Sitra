queremos hacer un sistema que sea capas de registras los atrasos de manera eficiente obteniendo los datos del alumno mendiante un sistema, esto para depues guarde la lista de atrasos para que el inspector registre una manera mas eficas y rapida los atrasos de los alumnos

Los sistemas que tenemos a concideracion para recolectar datos son:
1. un escaner de huella digital con una pantalla al costado que muestre que se registro el atraso del alumno x 
2. Un sistema de tarjetas que mediante un lector de tarjetas registre el atraso y que muestre en la pantalla del costado que se regitro el atraso del alumno x
queremos usar postgresql como base de datos 
tenemos la obligacion usar java para el codigo asi que para el diseño no queremos usar jframe ya que queremos usar algo mas flexible y moderno
queremos añadir plsql para los procedimeintos de la base de datos 

algunas entidades que tenemos a consideracion son:
Alumo
Representante(Apoderado)
Inspector/Profesor
Una tabla del Metodo de Recoleccion (Huella o tarjeta)


Concideraciones a futuro
Si logramos pasar esa fase de desarrollo queremos implementar este sistema de manera mas global incluyendo los registros de almuerzo junaeb para que los alumnos no se repitan almuerzo sin autorizacion y un sistema de asistencia que se regista en cada clase
