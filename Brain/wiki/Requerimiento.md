# Requerimiento

Necesidad o condición que debe cumplir un sistema. Se obtiene mediante [[Toma de Requerimientos]] y se puede documentar en formato [[Historia de Usuario|ágil]] o [[Caso de Uso|estructurado]], o en una [[Planilla de Requerimientos|planilla]].

*Ejemplo: una empresa desea controlar sus ventas → "El sistema debe permitir registrar una venta indicando cliente, productos, cantidades y forma de pago."*

## Funcional vs. no funcional

| | Requerimiento Funcional (el qué) | Requerimiento No Funcional (el cómo) |
|---|---|---|
| Describe | Acciones directas que el sistema debe hacer | Condiciones de calidad y entorno operativo |
| Ejemplos | Registrar clientes, eliminar productos, generar facturas, buscar empleados, calcular descuentos | Responder en menos de 3 segundos, operar 24/7, autenticación de usuarios, respaldos automáticos, compatibilidad móvil |

**Síntesis:** lo funcional hace que el sistema *sirva*; lo no funcional hace que el sistema *sobreviva*.
