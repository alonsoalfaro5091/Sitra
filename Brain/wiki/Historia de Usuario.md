# Historia de Usuario

Formato ágil para documentar un [[Requerimiento]], centrado en el usuario y el beneficio esperado — usado en metodologías ágiles/Scrum ([[Metodologías de Desarrollo]]).

**Fórmula:** Como [tipo de usuario], quiero [funcionalidad], para [beneficio].

*Ejemplo: "Como vendedor, quiero registrar una venta para mantener actualizado el inventario."*

## vs. Caso de Uso

| Historia de Usuario | [[Caso de Uso]] |
|---|---|
| Más breve | Más detallado |
| Describe una necesidad | Describe el flujo completo |
| Utilizado en metodologías ágiles | Utilizado en UML |
| Generalmente no incluye excepciones | Incluye excepciones (flujos alternativos) |
| Sigue el formato "Como..., quiero..., para..." | Contiene actores y flujos |
