# Proyecto de Software

Un proyecto tecnológico es un esfuerzo **temporal** (tiene inicio y fin) que produce un **resultado único**, tiene **objetivos definidos**, exige **calidad**, gestiona **riesgos** y requiere **recursos** (humanos, técnicos, financieros).

> El código es solo el subproducto. Un proyecto de software es un esfuerzo orquestado para transformar una necesidad latente en una solución tecnológica de alto valor — el éxito no se mide en líneas de código, sino en planificación precisa, participación activa de los usuarios y gestión inteligente de las restricciones.

## Proyecto vs. Operación

| | Proyecto (Creación) | Operación (Mantenimiento) |
|---|---|---|
| Duración | Temporal, con inicio y fin | Permanente, continua |
| Naturaleza | Produce un resultado único | Repite actividades de forma rutinaria |
| Objetivo | Resolver una necesidad específica | Mantener los procesos existentes funcionando |
| Ejemplo | Desarrollar una nueva app móvil | Brindar soporte técnico diario |

## Detonantes de un proyecto

Un proyecto nace para: resolver un problema, automatizar procesos, reducir tiempos/errores, mejorar la atención al cliente, o facilitar decisiones.

*Caso clínico de ejemplo: planillas manuales causan doble reserva y pérdida de datos → se decide construir una web app de gestión de citas.*
