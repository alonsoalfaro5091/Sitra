# Roles del Proyecto

Mapa del ecosistema de un [[Proyecto de Software|proyecto]], entre la visión de negocio y la ejecución técnica:

**Visión de negocio**
- **Cliente** — define la necesidad original y valida el producto final.
- **Usuario final** — utiliza el sistema diariamente y aporta retroalimentación real.

**Coordinación**
- **Jefe de Proyecto (PM)** — planifica, coordina y controla el esfuerzo completo.

**Ejecución técnica**
- **Analista de Requerimientos** — traduce la necesidad en especificaciones documentadas.
- **Diseñador UX/UI** — arquitecta la experiencia y las interfaces visuales.
- **Desarrollador** — escribe el código y programa la lógica de la aplicación.
- **Administrador de Base de Datos (DBA)** — diseña la estructura de almacenamiento de datos.
- **Tester (QA)** — ejecuta pruebas exhaustivas para garantizar la calidad.
